## v18 — Mobile / iPhone Responsive

Переработана мобильная компоновка для iPhone 14 Pro и близких ширин.

Главный экран:
- убран page-level horizontal overflow;
- шапка разделена на название и отдельную горизонтально прокручиваемую панель кнопок;
- статус модели обрезается ellipsis, а не растягивает страницу;
- чат и сообщения всегда остаются внутри viewport;
- composer учитывает safe-area слева/справа/снизу.

Visual ShopTurn:
- на телефоне больше не используется уменьшенная desktop-сетка;
- workflow steps прокручиваются локально по горизонтали;
- coach/status/actions переходят в вертикальную мобильную компоновку;
- кнопки действий строятся 2×2;
- sidebar/editor/review располагаются одной вертикальной колонкой;
- Program Header, geometry, setups и operation forms переходят в одну колонку;
- правая Validation/Review панель переносится вниз и не уходит за край экрана.

Desktop/iPad layout не меняется.


## v19 — Mobile Step Flow

Исправления по реальному iPhone:
- кнопка «Войти» теперь всегда с контрастным текстом;
- мобильный ShopTurn больше не показывает все desktop-блоки одновременно;
- текущий шаг Operator Workflow управляет тем, какой контент вообще виден;
- Drawing показывает только загрузку/разбор чертежа;
- Blank и Geometry показывают только текущую форму;
- Setups и Technology показывают навигацию + текущую форму;
- Tooling, Review и Simulation скрывают основной редактор и показывают только свой целевой экран;
- на Simulation больше нет графики заготовки и прочих форм под блоком подтверждения;
- длинное описание coach скрыто на телефоне: остаются текущий шаг, следующий вопрос, статус и действия.
