# Siemens Manual Memory — v25

В проект локально встроена полнотекстовая поисковая база двух руководств, предоставленных пользователем.

1. **SINUMERIK 840D sl/828D — Токарная обработка**
   - Руководство по эксплуатации
   - SINUMERIK Operate V4.8 SP3
   - 08/2018
   - 1008 страниц
   - основной источник точных параметров, циклов, масок и функций.

2. **SINUMERIK Operate / SinuTrain — Учебное пособие по токарной обработке с ShopTurn**
   - 05/2010
   - 222 страницы
   - источник логики ShopTurn, рабочего процесса и учебных примеров.

Архитектура:
- `src/manualKnowledge.generated.ts` содержит текст всех страниц обоих документов.
- `src/manualKnowledge.ts` выполняет локальный поиск без внешней БД и без отдельного API.
- Перед запросом к OpenAI релевантные страницы автоматически добавляются к инструкциям.
- Для ответов по фотографии supervisor повторно ищет руководство по техническим обозначениям,
  найденным в черновике ответа. Это позволяет, например, автоматически найти таблицу CYCLE92
  по видимым на экране `FS / FR / SR / X0 / X1 / X2`.
- OEM-функции станкостроителя по-прежнему не считаются стандартом Siemens без подтверждения.

Исходные PDF не требуются в Railway runtime: в deploy включён подготовленный текстовый индекс.
